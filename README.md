# Bot Trading H24

Bot de trading crypto automatique — paires EUR sur Binance. XGBoost ML + Groq AI.

## Installation (Windows)

1. Clic droit sur `INSTALL.ps1` > **Executer avec PowerShell**
2. Le script fait tout : Python, Git, dependances, venv, demarrage auto, mise a jour auto

## Acces dashboard

- LAN : `http://[IP]:5000`
- Partout via Tailscale : `http://[IP-Tailscale]:5000`

## Mises a jour

Automatique toutes les 30min. Manuelle : re-executer `INSTALL.ps1`.

BTC/EUR ETH/EUR BNB/EUR SOL/EUR XRP/EUR DOGE/EUR ADA/EUR LTC/EUR
